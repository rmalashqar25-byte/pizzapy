# Security policy

Py Pizza is currently an offline demonstration application. It does not process real orders or payments.

## Reporting a vulnerability

Please report security concerns privately through GitHub's security advisory feature. Do not include secrets, personal information, or exploit details in a public issue.

## Sensitive files

Never commit API keys, `.env` files, Android signing keys, `key.properties`, certificates, payment credentials, or customer data. The repository ignore rules cover the common local forms of these files.
